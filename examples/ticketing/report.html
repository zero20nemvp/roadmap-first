Jobs are the linchpin: jobs give features, features give stories.

  • J1 · jobWhen I announce an event, I want to sell tickets, so I keep the buyers' data for next time
    • F1Event page with ticket checkout
    • F2Buyer list the promoter owns and exports
  • J2 · jobWhen guests arrive, I want to check them in at the door, so the queue moves
    • F3QR ticket scan at the door
  • J3 · jobWhen I run more than one event, I want to run several events at once, so I don't rebuild each one
