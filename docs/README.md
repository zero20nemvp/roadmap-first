# 021 guide

021 is a coach that runs inside Claude Code. It takes you from an idea to **stage 1**, the smallest slice of your product that someone would pay for, and leaves you with a one-page brief you can build from.

You can read any page of this guide inside Claude Code with `/021 guide <page>`. For example, `/021 guide exercises`.

## The short version

1. Open Claude Code in a folder for your product, and type `/021 roadmap`.
2. Answer one question at a time. Say “I don't know” when you don't; the coach will help.
3. When every gap is filled, run `/021 view` to see your roadmap, and paste `./021/brief.md` into Claude on build day.
4. Build stage 1, put it in front of real customers, and test the unknowns on your list.
